# PythonProject1
# 影视收藏与观影记录管理系统

## 项目简介
这是一个基于Python开发的本地影视管理工具。用户可以记录自己想看或在看或看过的电影，支持评分、短评、搜索等。

## 技术栈
- 语言：Python 3
- 界面：Tkinter
- 数据库：SQLite
- 图表：Matplotlib

## 目录结构
- `main.py`：程序入口，负责界面展示与交互，即表现层。
- `db_module.py`：核心数据访问模块，封装了所有数据库操作，即数据访问层。
- `movie.db`：SQLite数据库文件。

## 运行方法
1. 确保安装了：`pip install matplotlib`
2. 运行主程序：`python main.py`
